# ☁️ Cloud-Based Online Examination System

A web-based online examination system developed using HTML, CSS and JavaScript.

This project allows students to log in, view available examinations, attend online multiple-choice examinations, answer questions, submit the examination and view their results automatically. The system also includes an admin dashboard for managing examination-related activities.

## 🚀 Live Website

https://https://jasminecse21.github.io/Cloud-Based-Online-Examination-System/

## Features

- Student Login
- Admin Login
- Student Dashboard
- Available Examinations
- Online MCQ Examination
- Examination Timer
- Automatic Score Calculation
- Result Page
- Admin Dashboard
- Exam Management Options

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase
- GitHub Pages
